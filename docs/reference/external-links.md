# External resources

Online references used during this restoration.

## WB4KDI (qsl.net)

- **Full TS-120S folder** (schematics, manuals, service bulletins): https://www.qsl.net/wb4kdi/Kenwood/TS-120S/
  - Download everything with:
    ```bash
    wget -r -np -nH --cut-dirs=3 -R "index.html*" -e robots=off --wait=1 -P TS-120S https://www.qsl.net/wb4kdi/Kenwood/TS-120S/
    ```
- **"Help, I just got a TS-120"** (troubleshooting guide and common problems): https://www.qsl.net/wb4kdi/Kenwood/TS-120S/TS-120_HELP.html
- **WB4KDI Kenwood index, TS-120 section**: https://www.qsl.net/w/wb4kdi/Kenwood/#TS-120
